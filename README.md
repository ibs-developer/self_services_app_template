# Expo Project Template 🚀

قالب مشروع Expo جاهز ومُعد مسبقًا بأفضل الممارسات لتسريع عملية بدء المشاريع الجديدة.

---

## ✨ الميزات الرئيسية

- **هيكل ملفات منظم:** يتم استخدام بنية `app` للتوجيه (Expo Router) مع مجلد `src` لجميع أكواد المنطق والمكونات.
- **أسماء مستعارة للمسارات:** تم إعداد المسارات باستخدام `@` للإشارة إلى مجلد `src` (مثال: `@/components`).
- **أدوات جودة الكود:** مُجهز بـ ESLint و Prettier لضمان كود نظيف ومتناسق.
- **ثوابت التصميم:** هيكل جاهز في `src/constants` لإدارة الألوان، الأبعاد، والخطوط بشكل مركزي.
- **التنقل المدمج:** يستخدم أحدث إصدار من Expo Router للتنقل القائم على الملفات.

---

## 🏁 كيفية البدء

### المتطلبات المسبقة

- تأكد من تثبيت [Node.js](https://nodejs.org/) (إصدار LTS موصى به).
- [Git](https://git-scm.com/).
- تطبيق [Expo Go](https://expo.dev/go) على هاتفك (iOS أو Android).

### 1. استنساخ القالب

للبدء، يمكنك استخدام هذا المستودع كقالب (Template) على GitHub بالضغط على زر "Use this template" أو استنساخه مباشرة:

```bash
git clone [رابط المستودع الخاص بك هنا] اسم-مشروعك-الجديد
cd اسم-مشروعك-الجديد
```

### 2. تثبيت الاعتماديات

```bash
npm install
```
أو إذا كنت تفضل `yarn`:
```bash
yarn install
```

### 3. تشغيل المشروع

```bash
npx expo start
```

سيؤدي هذا إلى بدء خادم التطوير. يمكنك بعد ذلك مسح رمز الاستجابة السريعة (QR code) باستخدام تطبيق Expo Go على هاتفك.

---

## 🛠️ الأوامر المساعدة (Scripts)

- **`npm run start`**: لتشغيل خادم التطوير.
- **`npm run android`**: لتشغيل التطبيق على محاكي Android.
- **`npm run ios`**: لتشغيل التطبيق على محاكي iOS.
- **`npm run lint`**: لفحص أخطاء الكود باستخدام ESLint.
- **`npm run format`**: لتنسيق جميع ملفات المشروع باستخدام Prettier.
